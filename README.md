# SIGAPKL-TKJ — Frontend

Tampilan aplikasi Sistem Informasi Giat Aktivitas PKL Kelas XII TKJ (HTML/CSS/JS murni, tanpa build).

- `index.html` — titik masuk (harus di akar repository agar GitHub Pages tidak 404)
- `css/style.css` — desain "Mint Modern Vocational OS"
- `js/config.js` — **isi `GAS_URL` dengan URL /exec backend Apps Script**
- `js/core.js`, `js/pages-*.js` — logika aplikasi

Langkah lengkap instalasi backend & deploy ada di `PANDUAN-INSTALASI.md`.
